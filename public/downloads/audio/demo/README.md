# Product demo narration

Drop the demo's narration clips in THIS folder. The investor deck's clips live one
level up (`public/downloads/audio/`) and are separate; the demo never reads them.

## Naming (exact)

`slide-01.mp3` ... `slide-10.mp3`  (lowercase, two digits, `.mp3`), in slide order.

| File | Slide | Animation plays out in about |
|------|-------|------------------------------|
| slide-01.mp3 | Welcome (storefront tour + contact form) | 36 s |
| slide-02.mp3 | Problem (the flood) | 24 s |

## How it behaves

- Auto-play (press **A**) advances when a clip ends. A missing or broken clip falls back to the
  time above, so a deck never gets stuck. You can add clips one at a time.
- Each slide's choreography (cursor, typing, flips, counters) stretches or shrinks to the clip's
  real length. Aim for roughly +/- 25% of the time above. Longer is always safe (the slide holds
  its last frame); much shorter than ~75% can clip the tail of slides with fixed-length moments
  (typing, the paper plane, the truck) - slides 1 and 4 most of all.
- Re-recording a slide: keep the same file name. Hard-refresh (Ctrl/Cmd+Shift+R) if the old clip
  still plays - browsers and GitHub Pages cache audio.
